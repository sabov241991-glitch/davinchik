Давинчик 💌 — мини-чат (Flask + Socket.IO)

Функции:
- Регистрация: ник, пароль, подтверждение пароля, "О себе"
- Первый зарегистрированный получает роль "гл.Администратор"
- Прихожая: "Зарегистрировано (N)", "Общение (X)"
- Комната "Общение": история, кнопка "Перейти к новым (N)"
- Системные события: приветствие нового, "/hi Имя"
- Антиреклама: авто-мут 24ч, событие видно всем

Запуск локально:
1) python -m venv venv && source venv/bin/activate (Windows: venv\Scripts\activate)
2) pip install -r requirements.txt
3) python main.py
4) Открыть http://localhost:8080

Render:
- Build Command: pip install -r requirements.txt
- Start Command: python main.py
